# AI Intraday Trading Agent (India) — Paper-Trading Research Platform

A research platform for intraday NSE equity strategies with an unusually heavy emphasis on *not trading*: the broker adapters are read-only, real-money order placement does not exist anywhere in the codebase, and every signal needs a human click before it's even simulated.

I built it to learn, in a disciplined way, whether a systematic intraday approach has any edge after Indian statutory costs. It was built with AI-assisted development tools over nine phases, each closed with a written audit (`PHASE7_AUDIT.md` … `PHASE9_AUDIT.md`). I own and maintain all of it.

> **Status and honest result so far:** Infrastructure is complete and tested. Evidence is not. Seven controlled paper sessions have produced one qualifying trade, far below the 30-trade minimum the platform itself enforces before it will issue any verdict. The current verdict, generated by the system, is `INSUFFICIENT LIVE PAPER DATA`. No live money has been, or will be, deployed on this.

## What's in it

**Data** — Pluggable providers (Angel One, Zerodha Kite, Upstox: quote endpoints only; historical CSV; mock for tests), Parquet storage, liquidity universe filter (turnover, price band, spread), market calendar, corporate-action adjustment, survivorship-bias handling, GIFT Nifty and global-market context, provider health checks with retry and cache.

**Strategies** — `VWAP + EMA(9/21) + RVOL` momentum, opening-range breakout, mean reversion; all behind a common `Strategy` base with a quality-filter layer and a market-regime classifier (trending / sideways / high-vol / gap).

**Backtesting and validation** — Event-driven engine, full Indian cost model (brokerage, STT, exchange fees, GST, SEBI charges, stamp duty) plus slippage, walk-forward and rolling walk-forward, Monte Carlo (including a dual enhanced variant), parameter-sensitivity sweeps, overfitting checks, concentration analysis, data-quality audit, and a qualification gate that a strategy must pass before it is allowed into paper trading.

**Paper trading** — Live tick streamer, 1-min/5-min candle builder, risk sizer (max 2% per trade), ATR-based brackets (SL 1.5×ATR, target 3.75×ATR → 1:2.5), auto-breakeven at +0.8R, profit lock at +1.5R, mandatory square-off at 15:15 IST, daily loss kill switch with a health watchdog that halts on stale data.

**Reporting** — Per-session and cumulative pilot reports with gross → costs → slippage → net attribution, win rate, expectancy, and a verdict that refuses to conclude anything below 30 trades.

**Surface** — FastAPI backend (`/docs`), Next.js 14 terminal with approval workflow, backtesting, data-health, live, phase-9 and go-live pages. Telegram alerts.

## Run it

```bash
cd backend
python -m venv venv && venv\Scripts\activate      # or source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env                              # paper mode is the default; leave it
uvicorn app.main:app --port 8000                  # API docs at http://localhost:8000/docs
pytest                                            # 69 test modules, 250+ tests

cd ../frontend && npm install && npm run dev      # http://localhost:3000
```

## Design decisions worth knowing

- **Read-only brokers by construction.** The adapters call quote endpoints only. A static scan for every order-placement pattern (`place_order`, `create_order`, …) is part of the phase audit and returns zero matches.
- **The platform decides when it has enough evidence, not me.** The verdict logic is coded; it can't be talked into optimism.
- **Costs first.** Indian statutory charges kill most intraday edges. The cost model was built in Phase 3, before any strategy was tuned, so every result shown is net.
- **Validation before paper, paper before anything else.** A strategy has to pass walk-forward, Monte Carlo and overfitting gates to qualify for paper trading at all.

## Known limitations

- Almost no live paper evidence yet; the system is a validated *instrument*, not a validated *strategy*.
- The momentum signal is a well-known public setup and should be assumed to have little or no edge until proven otherwise.
- SEBI's retail algo-trading framework requires broker registration for API-driven automation. This platform does not place orders, so it doesn't fall under it today; anything that changes that would need broker approval first.
